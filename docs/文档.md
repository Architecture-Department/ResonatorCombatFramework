# ResonatorCombatFramework 动画模块 — 功能文档

## 触发动画

```kotlin
// 通过映射器触发（必须使用 AnimationPlayData）
transformer.trigger(AnimationPlayData.of("animation.player.swing"))
transformer.trigger(AnimationPlayData("animation.player.my_anim"))

// 完整配置
transformer.trigger(
    AnimationPlayData.builder("animation.player.my_anim")
        .speed(2.0f)
        .type(AnimType.PLAY_ONCE)
        .controller(AnimationControllers.ACTION)
        .fadeIn(5)
        .fadeOut(10)
        .build()
)
```

参数说明：

- `animId` — 动画名称
- `controllerName` — 目标控制器，默认 MAIN
- `animType` — DEFAULT(按动画自身loop) / PLAY_ONCE / STOP_AT_LAST(保持最后一帧) / LOOP
- `startTime` / `endTime` — 起止时间(tick)，0=动画长度，负数=从尾部偏移
- `speedMultiplier` — 播放速度倍率，默认 1.0
- `durationTicks` — 在指定 tick 内播完（与 speedMultiplier 互斥）
- `boneConfig` — 骨骼配置覆盖
- `fadeInTicks` / `fadeOutTicks` — 淡入淡出时长(tick)，-1 使用默认值

## 停止 / 暂停 / 恢复

```kotlin
transformer.stop()                              // 主控制器淡出
transformer.stop(fadeOutTicks = 0)              // 立即停止
transformer.stopAll(fadeOutTicks = 5)           // 停止所有控制器
transformer.pause()                              // 冻结当前帧
transformer.resume()                             // 继续播放
transformer.pauseAll()
transformer.resumeAll()
```

## 状态查询

```kotlin
transformer.isActive()
transformer.getController(AnimationControllers.ACTION)
transformer.hasController(AnimationControllers.MAIN)
transformer.controllers()                        // 所有控制器
transformer.getActiveControllersSorted()          // 活跃控制器（按添加顺序）
transformer.getRenderableControllers()            // 可渲染控制器
transformer.findBlockingControllers(ctrl)         // 阻塞本控制器的高优控制器
```

## 控制器管理

预置注册的控制器：

| 名称      | Priority | 用途         |
|---------|----------|------------|
| ACTION  | 1000     | 动作层：物品切换检测 |
| MAIN    | 0        | 主控制器       |
| COMMAND | -1000    | 命令层        |

`isOverriding=true`（默认）：高优先级控制器的骨骼覆盖低优先级。
`isOverriding=false`：骨骼累加。

注册额外控制器：在 `AnimationControllerRegisterEvent` 中添加。

## 事件系统

### 时间线（timeline）

```json
"timeline": {
    "0.0": "v.slot = 1; @s my_event",
    "0.5": "/say hello",
    "1.0": ["v.x = 5", "/effect give @s speed 3 1"]
}
```

支持字符串（`;` 分隔）和数组两种格式。每段按前缀路由：

- 无前缀 → MoLang 表达式求值
- `/` 开头 → 斜杠命令（仅服务端执行）
- `@s` 开头 → 实体事件（预留，仅日志）

时间线双端执行。

### 音效（sound_effects）

```json
"sound_effects": {
    "0.5": { "effect": "minecraft:entity.player.attack.crit" },
    "1.0": [{ "effect": "minecraft:block.anvil.land", "locator": "right_hand" }]
}
```

参数：`effect`(音效ID) / `locator`(定位器名称) / `pre_effect_script`(预执行MoLang)
仅客户端执行，通过 BrModel.computeLocatorGlobalMatrix 解析位置。

### 粒子（particle_effects）

```json
"particle_effects": {
    "0.3": { "effect": "minecraft:crit" },
    "0.8": { "effect": "minecraft:heart", "locator": "body" }
}
```

参数：`effect`(粒子ID) / `locator`(定位器名称) / `bind_to_actor`(默认true) / `pre_effect_script`
仅客户端执行。

### 触发流程

```
控制器 tickBackend → collectEventsAt(anim)
  → 遍历 sounds/particles/timelines，比较 animTime
  → firedEvents 防重复，返回 AnimationEventsToFire
  → manager.queueEvents(events)
  → tickAnimations → remerge → firePendingEvents
     → timelines: 双端 apply(entity, data)
     → sounds/particles: 仅客户端
       mapper.playSoundEffect(sound, brModel, proxyModel, data)
```

## 骨骼配置（rcf/animdatas/）

```json
{
    "transition": 3,
    "fade_in": 5,
    "fade_out": 5,
    "bones": {
        "head": { "lock": false, "rot.x": true },
        "left_arm": { "blend": true }
    },
    "timeline": {
        "0.0-0.5": { "bones": { "head": { "lock": true } } }
    },
    "extra_bones": [
        { "name": "extra_arm", "parent": "body", "pivot": [0, 24, 0] }
    ]
}
```

骨骼标志：`lock` / `blend`(参与crossfade) / `transition` / `fade_in` / `fade_out`
轴控制：`pos.x` / `pos.y` / `pos.z` / `rot.x` / `rot.y` / `rot.z` / `scale.x` / `scale.y` / `scale.z`
轴锁定：`pos.lock` / `rot.lock` / `scale.lock`

## 过渡效果

| 场景        | blendFactor | 动画时间 | 说明                                        |
|-----------|-------------|------|-------------------------------------------|
| 从 IDLE 启动 | 0→1         | 冻结   | 权重递增，骨骼在冻结时间计算                            |
| 播放中切换     | 0→1         | 冻结   | transitionSource 快照 + crossfadeStep 混合旧→新 |
| 自然结束/stop | 1→0         | 冻结   | 权重递减                                      |
| 立即清除      | —           | —    | forceClear() 回到 IDLE                      |

每 tick blendFactor 步进 `1/currentTransitionTicks`，不受帧率影响。
transitionSource 保存旧动画骨骼快照（含 emptyMask）。

## MoLang 表达式

### 变量

| 示例             | 说明                  |
|----------------|---------------------|
| `v.slot = 1`   | 实体级全局变量，同 tick 共享   |
| `query.health` | 实体状态查询值（惰性求值，每帧实时）  |
| `temp.i`       | 临时变量（for_each 自动创建） |

MolangData 作为 AttachmentType 附加到实体，`MolangData.of(entity)` 获取。

### 作用域

```kotlin
val data = MolangData.of(entity)
data.withScope { scope ->
    scope.setLocal("temp.x", 5.0)
    expr.eval(scope)
    val result = scope.getLocal("temp.x")
}
```

`temp.*` → scope 局部 / `v.*` → 全局透传

## 动画 JSON 文件

路径：`assets/<namespace>/rcf/animations/<name>.json`

```json
{
    "animations": {
        "animation.player.my_anim": {
            "loop": true,
            "animation_length": 2.0,
            "anim_time_update": "query.anim_time + query.delta_time",
            "bones": {
                "left_arm": {
                    "position": { "0.0": [0, 0, 0], "1.0": [5, 0, 0] },
                    "rotation": { "0.0": [0, 0, 0], "1.0": [-90, 0, 0] }
                }
            }
        }
    }
}
```

键帧插值模式：LINEAR（默认） / STEP / CATMULLROM，值支持 MoLang 表达式。

## 几何模型

路径：`assets/<namespace>/rcf/models/<name>.json`

```json
{
    "minecraft:geometry": [{
        "description": { "identifier": "geometry.default" },
        "bones": [
            { "name": "body", "pivot": [0, 0, 0], "cubes": [...] }
        ],
        "locators": {
            "right_hand": ["right_arm", 0, 0, 0]
        }
    }]
}
```

定位器可在几何级别或骨骼级别定义，运行时存入 BrModel.locators。
音效／粒子事件通过 `computeLocatorGlobalMatrix(name, proxyModel)` 获取全局坐标。

## 物品定位器

`left_item` / `right_item` 骨骼控制物品（武器）渲染位置，`ItemInHandLayerMixin` 自动应用。

## 网络同步

`TriggerPlayerPayload` / `StopPlayerPayload` / `PausePlayerPayload` / `ResumePlayerPayload`
服务端收到 → 执行 → `PacketDistributor.sendToPlayersTrackingEntityAndSelf` 广播。
不持久化，不玩家间同步初始状态。
