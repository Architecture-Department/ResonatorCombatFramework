# ResonatorCombatFramework 动画模块 — 功能参考

## 触发动画

入口 `EntityAnimationMapper.trigger(playData: AnimationPlayData)`：

```kotlin
// 简单触发
transformer.trigger(AnimationPlayData.of("animation.player.swing"))

// Builder 完整配置
transformer.trigger(
    AnimationPlayData.builder("animation.player.my_anim")
        .speed(2.0f)
        .type(AnimType.PLAY_ONCE)
        .controller(AnimationControllers.ACTION)
        .fadeIn(5)
        .fadeOut(10)
      .startAt(0)
      .endAt(40)
      .boneConfig(myConfig)
        .build()
)
```

### AnimationPlayData 字段

| 字段                    | 类型                   | 默认      | 说明                                |
|-----------------------|----------------------|---------|-----------------------------------|
| animId                | String               | 必填      | 动画名称                              |
| controllerName        | ResourceLocation     | MAIN    | 目标控制器                             |
| animType              | AnimType             | DEFAULT | 覆盖动画自身 loop                       |
| startTime             | Int                  | 0       | 起始时间(tick)                        |
| endTime               | Int                  | 0       | 结束时间(tick)，0=播完，负数=长度-N           |
| speedMultiplier       | Float                | 1.0     | 速度倍率                              |
| durationTicks         | Int                  | 0       | 指定 tick 内播完（与 speedMultiplier 互斥） |
| originalAnimLengthSec | Float                | 0       | 配合 durationTicks 计算实际速度           |
| boneConfig            | ProxyBoneConfigData? | null    | 骨骼配置覆盖                            |
| fadeInTicks           | Int                  | -1      | 淡入时长(tick)，-1 用默认值                |
| fadeOutTicks          | Int                  | -1      | 淡出时长(tick)，-1 用默认值                |

### AnimType

| 值            | 行为                   |
|--------------|----------------------|
| DEFAULT      | 使用动画 JSON 中的 loop 字段 |
| PLAY_ONCE    | 播放一次后淡出              |
| STOP_AT_LAST | 播放一次，停最后一帧（不淡出）      |
| LOOP         | 强制循环                 |

```kotlin
transformer.resumeAll()
```

|---------|----------|-------------|

## 状态机

```
IDLE ──trigger──→ TRANSITIONING ──blend≥1──→ PLAYING
  ↑                                                │
  │                                                │ stop / 动画结束
  │                                                ↓
  └───────── forceClear ←─── FADING_OUT ←──────────┘
                          ↑
                          │ pause
                     PAUSED
                          │ resume
                          └──→ TRANSITIONING（淡入中）或 PLAYING
```

| 状态            | blendFactor | 动画时间 | tickAdvance 行为                                       |
|---------------|-------------|------|------------------------------------------------------|
| IDLE          | 0           | —    | 跳过                                                   |
| TRANSITIONING | 0→1/ticks   | 冻结   | tickBackend(freezeTime=true) 计算骨骼 + crossfadeStep 混合 |
| PLAYING       | 1           | 推进   | tickBackend 正常推进 + checkPlaybackBounds               |
| FADING_OUT    | -1/ticks→0  | 冻结   | tickBackend(freezeTime=true) 计算骨骼                    |
| PAUSED        | 不变          | 冻结   | 跳过                                                   |

## crossfade 过渡

### trigger() 时序

```kotlin
snapshotTransitionSource()  // 旧动画骨骼快照（含 emptyMask）
proxyModel.bones.clear()
currentAnim?.computeAndWrite(animTime, proxyModel, data)  // 新动画第0帧
affectedBones = ...          // 更新为新动画的骨骼集合
if (transitionSource != null) crossfadeStep()  // 首帧混合，保证连续
```

### tickAdvance 时序

```kotlin
checkPlaybackBounds()      // 检查动画是否结束
tickBlend()                // blendFactor += 1/transitionTicks

if PLAYING:
advanceTickCount++
tickBackend(gameTime, ...)  // 推进 animTime + 计算骨骼
else:
tickBackend(0f, ..., freezeTime = true)  // 冻结时间 + 计算骨骼

if TRANSITIONING && transitionSource != null:
crossfadeStep()  // lerp(transitionSource → proxyModel, blendFactor)

// 状态转移
if TRANSITIONING && blendFactor >= 1f → PLAYING, transitionSource = null
if FADING_OUT && blendFactor <= 0f → forceClear() → IDLE
```

### crossfadeStep 细节

```kotlin
val src = transitionSource
// 旧动画独有骨骼重置为 identity
proxyModel 中不在 affectedBones 的骨骼 → pos =0, rot = 0, scale = 1
// 补全缺失骨骼
proxyModel 中有但 src 没有的 → src 添加 identity
        src 中有但 proxyModel 没有的 → proxyModel 添加 identity
// 按 blendFactor 混合
        for each bone : lerp (src.bone → proxyModel.bone, blendFactor)
// 同步 emptyMask: fromBone 或 toBone 有数据即标记为非空
```

## 骨骼合并（remerge）

### tickAnimations 中的流程

```kotlin
tickAnimations():
prevMergedProxy ← mergedProxy 快照（供渲染插值）
for each controller : tickAdvance ()
remerge()
mergedFlags.clear()
mergedProxy.bones.clear()
coveredBones = emptySet()
for each active controller:
weight = effectiveWeight
mergedFlags ← resolveBoneFlags(animTime)
for each bone in controller . proxyModel . bones :
mb = mergedProxy.getOrCreate(name)
if bone in coveredBones && isOverriding:
mb ← identity, mark empty
mb.pos += bone.pos * weight
mb.rotation += bone.rotation * weight
mb.scale += (bone.scale - 1) * weight
// 其中 bone.scale.add(bone.scale.sub(1).mul(weight))
coveredBones += affectedBones
```

### tickAndRender 中的流程

```kotlin
tickAndRender():
for each controller : tickRender (deltaSec)
// 仅 PLAYING 时清理：移除 proxyModel 中不在 affectedBones 的骨骼
remerge()          // 同 tickAnimations 的 remerge
getInterpolatedProxy(partialTick)
// 逐骨骼 lerp(prevMergedProxy → mergedProxy, partialTick)
applyRootTransform(interpolatedProxy, poseStack, flags)
applyProxyToModel(interpolatedProxy, model, flags)
```

### BoneTransformUtil 骨骼应用

```kotlin
// root → PoseStack（Y 翻转）
val t = computeForPoseStack(bone, flags, weight = 1, flipY = true)
poseStack.translate(t.pos)
poseStack.mulPose(rotationZYX(t.rot))
poseStack.scale(t.scale)

// 普通骨骼 → ModelPart
val t = computeForModelPart(bone, flags, weight = 1)
if lockPos: part.x = initialPose.x+t.pos.x
if lockRot: part.xRot = initialPose.xRot+t.rot.x
if lockScale: part.xScale = 1+(t.scale.x-1)
```

## 骨骼配置 ProxyBoneConfigData

### JSON 格式 (`rcf/animdatas/<name>.json`)

```json
{
  "transition": 3,
  "fade_in": 5,
  "fade_out": 5,
  "bones": {
    "head": {
      "lock": false,
      "rot.x": true
    },
    "left_arm": {
      "blend": true
    }
  },
  "timeline": {
    "0.0-0.5": {
      "bones": {
        "head": {
          "lock": true
        }
      }
    }
  },
  "extra_model_id": "geometry.extra_part",
  "extra_model": {
    "minecraft:geometry": [
      ...
    ]
  }
}
```

### 解析

`ProxyBoneConfigData.parse(json, isClient)`：

- `extra_model_id` — 从 `BedrockModelRegistry` 按 ID 查找已注册模型
- `extra_model` — 内联 JSON 解析为 `BakingBrModel`
- 存为 `extraModel: BakingBrModel?`

### 骨骼标志

| key                              | 默认           | 说明           |
|----------------------------------|--------------|--------------|
| lock                             | true         | 锁定骨骼（不应用动画）  |
| blend                            | true         | 参与 crossfade |
| transition                       | true         | 参与过渡         |
| fade_in                          | → transition | 参与淡入         |
| fade_out                         | → transition | 参与淡出         |
| pos.x / pos.y / pos.z            | true         | 位置轴启用        |
| rot.x / rot.y / rot.z            | true         | 旋转轴启用        |
| scale.x / scale.y / scale.z      | true         | 缩放轴启用        |
| pos.lock / rot.lock / scale.lock | true         | 各轴锁定         |

### 使用流程

```
BedrockAnimationController.trigger():
    activeBoneConfig = finalConfig                // 设当前配置
    extraModel = finalConfig.extraModel            // 取额外模型
    manager.rebuildBones()                         // 重算骨骼

rebuildBones():
    brModel.set(bakingBrModel)                     // 基础模型
    for each controller with extraModel:
        brModel.overwriteAdd(controller.extraModel) // 合并额外骨骼
```

## 模型系统

### 层次

```
BakingBrModel (JSON 解析)
  ├── BakingBrBone — 骨骼定义 (name/parent/pivot/rotation/cubes/locators)
  ├── BakingBrCube — 立方体 (inflate/origin/size/rotation)
  └── BakingBrLocator — 定位器 (name/boneName/position)

BrModel (运行时)
  ├── BrBone — bones: MutableMap<String, BrBone>
  ├── BrCube — cubes: MutableList<BrCube>
  └── BrLocator — locators: MutableMap<String, BrLocator>

ProxyModel (每帧变换)
  └── ProxyBone — name/pos(Vector3f)/rotation(Vector3f)/scale(Vector3f)/emptyMask
```

### BrModel 方法

| 方法                                           | 说明            |
|----------------------------------------------|---------------|
| computeBoneGlobalMatrix(name, proxyModel)    | 骨骼全局矩阵（含父链继承） |
| computeLocatorGlobalMatrix(name, proxyModel) | 定位器全局矩阵       |
| clear()                                      | 清空骨骼和定位器      |
| set(BakingBrModel)                           | 完全替换          |
| add(BakingBrModel)                           | 合并不覆盖已有       |
| overwriteAdd(BakingBrModel)                  | 合并覆盖已有        |

### 模型加载路径

`assets/<namespace>/rcf/models/<name>.json` → `BedrockModelRegistry` → `BakingBrModel.parses()`

## 事件系统

### 时间线（timeline）

```json
"timeline": {
"0.0": "v.slot = 1",
"0.5": "/say hello",
"1.0": ["v.x = 5", "/effect give @s speed 3 1"],
"1.5": "@s my_event"
}
```

支持字符串（`;` 分隔）和数组格式。路由规则：

- 无前缀 → `MathParser.compileMolang(trimmed)` 求值
- `/` 开头 → 斜杠命令（仅服务端 `ServerLevel`）
- `@s` 开头 → 实体事件（当前仅日志）

执行：`BakingBrAnimationTimeline.apply(entity, data)`，双端。

### 音效（sound_effects）

```json
"sound_effects": {
    "0.5": { "effect": "minecraft:entity.player.attack.crit" },
    "1.0": [{ "effect": "minecraft:block.anvil.land", "locator": "right_hand" }]
}
```

参数：`effect`(ResourceLocation) / `locator`(骨骼或定位器名) / `pre_effect_script`(MoLang)
执行：`BakingBrAnimationSound.apply(entity, brModel, proxyModel, data)`，仅客户端。
位置通过 `brModel.computeLocatorGlobalMatrix(locatorName, proxyModel)` 获取。

### 粒子（particle_effects）

```json
"particle_effects": {
    "0.3": { "effect": "minecraft:crit" },
    "0.8": { "effect": "minecraft:heart", "locator": "body" }
}
```

参数：`effect`(ResourceLocation) / `locator` / `bind_to_actor`(默认 true) / `pre_effect_script`
执行：`BakingBrAnimationParticle.apply(entity, brModel, proxyModel, data)`，仅客户端。

### 触发阶段

```
① collectEventsAt(anim) — 控制器内，遍历 sounds/particles/timelines
   比较 animTime ≥ time，firedEvents 防重，返回 AnimationEventsToFire
② manager.queueEvents(events) — 入队
③ firePendingEvents() — 在 remerge 后统一执行
   timelines: 双端 apply(entity, context)
   sounds/particles: 仅客户端
     mapper.playSoundEffect(it, brModel, mergedProxy, data)
```

## MoLang 表达式

### 接口

```kotlin
interface MolangValue {
  fun eval(context: MolangData? = null): Double
  fun eval(entity: Entity): Double
  fun eval(controller: IEntityAnimationController<*>): Double
  fun isMutable(): Boolean
}
```

### 变量存储

`MolangData` 作为 `AttachmentType` 挂载在实体上：

- `vars: HashMap<String, DoubleSupplier>` — 所有变量和查询值
- `resolve(name)` → `vars[name]?.asDouble ?: 0.0`
- `assign(name, value)` → 过滤 `query.`/`context.`/`geometry.`/`material.`/`texture.` 前缀

### MolangScope

```kotlin
class MolangScope(global: MolangData) : MolangData()
// 继承 MolangData，可当作 context 传入 eval()
locals: HashMap<String, Double>  // 临时变量层
resolve(name) → locals[name] ?: global.resolve(name)
assign(name, value) → temp.* 写 locals，v.* 透传 global

fun MolangData.withScope(block: (MolangScope) -> T): T
```

## 动画 JSON 文件

路径：`assets/<namespace>/rcf/animations/<name>.json`

```json
{
    "animations": {
        "animation.player.my_anim": {
            "loop": true,
            "animation_length": 2.0,
            "anim_time_update": "query.anim_time + query.delta_time",
            "bones": {
                "left_arm": {
                    "position": { "0.0": [0, 0, 0], "1.0": [5, 0, 0] },
                  "rotation": {
                    "0.0": [
                      0,
                      0,
                      0
                    ],
                    "1.0": [
                      -90,
                      0,
                      0
                    ]
                  },
                  "scale": {
                    "0.0": [
                      1,
                      1,
                      1
                    ]
                  }
                }
            }
        }
    }
}
```

- 键帧插值：LINEAR（默认）/ STEP / CATMULLROM
- 值支持 MoLang 表达式

- `anim_time_update`: 自定义时间推进表达式，默认 `query.anim_time + query.delta_time`

## 网络同步

| 包                    | 方向  | 服务端行为                             |
|----------------------|-----|-----------------------------------|
| TriggerPlayerPayload | C↔S | 执行 trigger + PacketDistributor 广播 |
| StopPlayerPayload    | C↔S | 执行 stop + 广播                      |
| PausePlayerPayload   | C↔S | 执行 pause + 广播                     |
| ResumePlayerPayload  | C↔S | 执行 resume + 广播                    |

服务端收到触发/停止/暂停/恢复 → 本端执行 → 广播给所有追踪玩家和自身。
