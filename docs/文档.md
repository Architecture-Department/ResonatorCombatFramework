# ResonatorCombatFramework（共鸣战斗框架）

## 模块定位

提供**战斗框架**和**玩家动画系统**的中间层模块，依赖 GoldenBoughsLib。Kotlin 优先，仅 mixin 保留 Java。

## 命名规范

- **接口**: `I` 前缀（如 `IPlayerRcf`, `IEntityRcf`）
- **工具类/Object**: 名词直接命名（如 `PlayerAnimationHelper`, `ModelUtil`）
- **Mixin 唯一字段/方法**: 使用 `resonator_combat_framework$` 前缀，混淆后防止 mod 间冲突
- **包名**: 全小写 snake_case
- **常量**: `UPPER_SNAKE_CASE`，在 `companion object` 或 `object` 中
- **ID 引用**: 使用静态变量（如 `Rcf.ID`），不硬编码字符串

## 事件规则

- `@EventBusSubscriber` 自动选择 bus，通常只需 `modid` 和 `value`
- 事件按事件类分类，放在 `events/`（公共）或 `events/client/`（客户端专属）
- 事件 subscriber 只做转发，业务逻辑放工具类
- 跨类调用必须带类名（`ClassName.method()`）

## 玩家动画系统

### 动画引擎

使用 **eyelib 21.1.14** (TT432/eyelib) 作为动画计算引擎，不替换原版渲染。
`AnimationComponent.setup()` 直接注册 `BrAnimationEntry` / `BrAnimationController`，原生支持多动画并发和状态机。

### 公开 API

外部通过 `IPlayerAnimator` 接口操作：

| 方法                      | 作用                          |
|-------------------------|-----------------------------|
| `trigger(animId)`       | 触发动画。已存在则重启; 否则交叉淡入淡出覆盖当前动画 |
| `stop()`                | 停止所有动画，带过渡淡出                |
| `stopAnimation(animId)` | 移除指定动画                      |
| `isActive()`            | 是否有动画正在播放/过渡中               |

### 数据流

```
物品/命令触发
  → PlayerAnimationHelper.trigger / stop (通过 IPlayerAnimator)
  → AnimatePlayerPayload 双端网络包
  → PlayerAnimationTransformer.trigger(animId)
  → 过渡: blendFactor lerp (由 currentTransitionTicks 控制速度)
  → LivingEntityRendererMixin.applyTransform()
  → BrAnimator.tickAnimation() → BoneRenderInfos
  → applyBone() → 叠加到 ModelPart
```

### 核心类

| 类                                   | 作用                                                |
|-------------------------------------|---------------------------------------------------|
| `IPlayerAnimator` (`api/`)          | 公开 API 接口                                         |
| `PlayerAnimationTransformer`        | 实现 IPlayerAnimator, 管理动画生命周期/过渡/交叉淡入淡出/骨骼变换       |
| `PlayerAnimationSetup`              | RenderData 初始化（模型 + 渲染配置）                         |
| `PlayerAnimationHelper` (`helper/`) | 双端便捷方法: trigger/stop/request/push                 |
| `EyeLibUtil` (`util/`)              | eyelib 操作集中管理 (AnimationManager/Data/animate map) |
| `AnimatePlayerPayload` (`payload/`) | `ToServerAndClientPayload` 双端网络包                  |
| `PlayerProxyProvider` (`mixed/`)    | Mixin 接口, 返回 `IPlayerAnimator`                    |
| `LivingEntityRendererMixin`         | 注入 `render()`, 调用 `applyTransform`                |
| `PlayerMixin`                       | 持有 `PlayerAnimationTransformer` `@Unique` 实例      |

### 过渡系统

- `RcfBoneConfig.transitionTicks: Int` — tick 制, 默认 10 (0.5 秒), 0 = 即时
- `currentTransitionTicks` 直接存储配置值, 每帧步长 `(deltaSec * 20f) / currentTransitionTicks`
- 三种模式: fade-in / fade-out / 交叉淡入淡出
- 详见 `docs/PLAYER_ANIMATION.md`

### 测试命令

```
/test_anim <target> <anim_id>    — 触发动画
/test_anim_stop <target>         — 停止动画
```
