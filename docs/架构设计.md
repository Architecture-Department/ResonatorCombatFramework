# 玩家动画模块架构

## 继承链

```
IAnimationMapper                        ← 根接口: 生命周期+控制器管理+映射
  ↑
EntityAnimationMapper<T:Entity, M>      ← 控制器注册+配置解析+trigger/stop/stopAll
  ↑
LivingEntityAnimationMapper<T, M>       ← resolveBoneFlags+animTimeTracker
  ↑
HumanoidEntityAnimationMapper<T, M>     ← applyProxyToModel(6人形骨骼)+applyProxyBone+applyProxyToItem
  ↑
PlayerAnimationMapper                   ← EyeLibAnimationController+渲染入口+jacket/sleeve/pants
```

## 控制器层

```
IAnimationController                    ← 纯接口: blendFactor/tick/trigger/stop
  ↑
EyeLibAnimationController              ← 过渡+BrAnimator+ProxyModel lerp
  ├── EyelibBoneController             ← infos.infos全量遍历→ProxyBone
  └── EyelibItemController             ← right_item/left_item→ProxyLocator
```

## 数据流

```
trigger(animId)
  → EntityAnimationMapper.trigger → resolveController→resolveConfig
  → EyeLibAnimationController.trigger
    → 深拷贝当前 proxyModel (旧帧快照)
    → 清空 eyelib, 注册新动画
    → blendFactor=0→1

每帧 applyTransform:
  → EyeLibAnimationController.tick()
    → BrAnimator.tickAnimation() → BoneRenderInfos
    → EyelibBoneController: infos.infos→ProxyBone (GlobalBoneIdHandler反向查询)
    → EyelibItemController: right_item/left_item→ProxyLocator
    → previousProxyModel lerp→proxyModel (交叉淡入淡出)
  → HumanoidEntityAnimationMapper: ProxyModel→ModelPart (6人形骨骼)
  → PlayerAnimationMapper: +jacket/sleeve/pants
  → applyProxyToItem: locator→PoseStack
```

## 过渡系统

ProxyModel lerp: 深拷贝旧帧→清空eyelib→只注册新动画→每帧lerp(old,new,bf)
无 eyelib 双动画注册, 无 previousAnimations/multiplier/saveAnimTimes

## 接口纯度

根基接口 (`controller/IAnimationController`, `controller/IBoneController<in, in>`, `controller/IItemController<in, in>`)
零外部 import, 通过泛型推迟类型绑定到 `eyelib/` 实现层。
