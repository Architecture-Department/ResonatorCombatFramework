# 玩家动画模块架构

## 继承链

```
IAnimationMapper                        — 根接口: 生命周期+控制器管理+骨骼冲突
  ↑
EntityAnimationMapper<T:Entity, M>      — 控制器注册+tick/trigger/stop, root PoseStack
  ↑
LivingEntityAnimationMapper<T, M>       — animTimeTracker + boneConfigs
  ↑
HumanoidEntityAnimationMapper<T, M>     — 6人形骨骼 applyProxyBone + 物品 applyProxyToItem
  ↑
PlayerAnimationMapper                   — EyeLibAnimationController + jacket/sleeve/pants
```

## 控制器层

```
IAnimationController                    — 纯接口: blendFactor/tick/trigger/stop/pause/resume
  ↑
BaseAnimationController                 — 状态机 + crossfade + 播放边界检查
  ↑
EyeLibAnimationController               — eyelib 后端适配
  ├── EyelibBoneController              — BoneRenderInfos → ProxyModel.bones
  └── EyelibLocatorController           — locator 读取（保留，暂无实际作用）
```

## 状态机

```
                    trigger()
IDLE ───────────────────────→ TRANSITIONING
  ↑                               │ blendFactor→1
  │                               ↓
  │                           PLAYING
  │                            │  │
  │                 pause()    │  │ stop()
  │                            ↓  ↓
  │                         PAUSED  FADING_OUT
  │                          │         │ blendFactor→0
  │               resume()   │         ↓
  │                          │       IDLE
  │                          ↓
  │              forceClear()/stopImmediate()
  └─────────────────────────────────────────┘
```

## 数据流（完整链路）

```
触发侧:
PlayerAnimationHelper.triggerPlayerAnimation(config)
  → 服务端: serverTriggerPlayerAnimation + AnimatePlayerPayload 广播
  → 客户端: clientTriggerPlayerAnimation
    → PlayerAnimationMapper.trigger(config)
      → boneConfigs[animId] = config.boneConfig ?: loadedConfig
      → controller.resolvedBoneConfig = used
      → controller.trigger(config)
        → loadAnimation → 快照 transitionSource → 清空 proxyModel
        → 设置 currentTransitionTicks(fadeIn) → blendFactor=0→1
        → freezeAllAtFrameZero + rebuildBackend

渲染侧 (每帧):
PlayerAnimationMapper.tickAndRender(model, partialTick, poseStack)
  → tick() → 每个控制器.tick(deltaSec)
    → tickBlend(deltaSec) → blendFactor 渐变
    → 清除不属于 affectedBones 的旧骨骼
    → freezeAllAtFrameZero (TRANSITIONING 时)
    → checkPlaybackBounds() → 处理动画结束
    → tickBackend() → EyelibBoneController 写入 proxyModel
    → crossfadeStep() → 逐骨骼 lerp(transitionSource, proxyModel, blendFactor)
        ├── shouldBlend=true  → fromBone.pos.lerp(toBone.pos, blendFactor)
        └── shouldBlend=false → fromBone = toBone (硬切)
  → collectProxyModels() → 合并多控制器(按优先级)
  → resolveMergedFlags() → 合并骨骼配置(timeline 求值)
  → applyRootTransform(proxyModels, poseStack, weight)
  → applyProxyToModel(proxyModels, model, flags, weight)
    → applyProxyBone: ProxyBone → ModelPart
      ├── lockPos     → (initialPose + anim) * weight
      ├── !lockPos    → anim * weight (叠加原版)
      └── isEnabled   → 逐轴跳过
```

## 多控制器合并（Mapper 职责）

```
控制器的 proxyModels
  → getRenderableControllers()
    → 按优先级降序排序
    → 高优先级 isOverriding 控制器阻塞低优先级的同骨骼
  → collectProxyModels() → List<ProxyModel>
  → applyProxyToModel(proxyModels, model, flags, weight)
```

## 骨骼配置（ProxyBoneFlags）

内部用 `Map<String, Boolean>` 存储，Kotlin 扩展函数访问（nullable receiver）。

内置 key 用 `.` 分层：`lock`, `blend`, `transition`, `pos.x/y/z`, `pos.lock`, `rot.*`, `scale.*`。

第三方可扩展 `flags["custom.sub"] = true`。

## 配置优先级

```
AnimationPlayConfig.boneConfig (运行时传入)
  > ProxyBoneConfigLoader.getConfig(animId) (JSON 加载)
    > ProxyBoneConfigData.DEFAULT_FLAGS (代码默认)
```

配置解析时 resolveBoneFlags(animTime) 会叠加 timeline 条目。

## 接口纯度

- `IAnimationController` — 零外部 import，纯 Kotlin 接口
- `IBoneController<in TRawData, in TProxyModel>` — 泛型推迟类型绑定
- `IAnimationMapper` — 根接口，定义动画映射规范

eyelib 依赖全部隔离在 `controller/eyelib/` 包内。
